# Hotel Reservation System

## Project Description
This is a simple Hotel Reservation System developed using Java. It helps users manage hotel room reservations.

## Features
- View available rooms.
- Book hotel rooms.
- Manage room reservations.
- Store reservation details.
- Display booking information.

## Technologies Used
- Java
- Classes and Objects
- Arrays
- Conditional Statements
- Loops

## How to Run
1. Download HotelReservationSystem.java.
2. Open the terminal or command prompt.
3. Compile using `javac HotelReservationSystem.java'
4. Run using `java HotelReservationSystem'
